🎓 Sistema de Gestão de Alunos em C++
Sistema interativo desenvolvido em C++ para gerenciar cadastros acadêmicos, permitindo inclusão de novos estudantes, consulta individual, listagem geral e atualização de notas.

🚀 Funcionalidades
Cadastrar Aluno: Armazena Nome, Idade, Matrícula e Nota Final com verificação de matrículas duplicadas.
Listar Alunos: Exibe todos os cadastros ativos formatados em tabela.
Buscar por Matrícula: Localiza e exibe os dados individuais de um aluno específico.
Atualizar Nota Final: Permite alterar a nota de um aluno cadastrado no sistema.
🛠️ Conceitos e Boas Práticas Aplicadas
Estruturas de Dados (struct): Agrupamento de dados de tipos diferentes sob uma mesma entidade.
Vetor de Structs: Armazenamento em memória para até 100 registros.
Modularização por Funções: Divisão do sistema em módulos independentes reutilizáveis.
Passagem por Referência (&) e const: Otimização e proteção da integridade dos dados na memória.
💻 Como Executar o Projeto
Faça o download ou clone este repositório.
Abra o arquivo main.cpp em uma IDE como *Code::Blocks, *Dev-C++ ou VS Code.
Compile e execute o código no terminal de sua preferência.
Projeto desenvolvido para a disciplina de Algoritmos e Programação.
